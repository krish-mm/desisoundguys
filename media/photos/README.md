# Photos for the Desi Sound Guys site

Drop files in this folder. The gallery and lightbox look for these names and will use them automatically once they are here. Do not add stock photos.

## Expected files

- `pic-1.jpg` through `pic-10.jpg`
- `.webp` is also fine (`pic-1.webp` through `pic-10.webp`). If both exist, the site prefers `.webp`.

## Where they appear

All ten slots are in the Gallery grid. Click a photo to open the lightbox.

## Recommended format

- JPEG or WebP
- About 1600px on the long edge
- SRGB, reasonably compressed so the page stays fast
