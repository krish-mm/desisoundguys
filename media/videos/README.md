# Videos for the Desi Sound Guys site

Drop files in this folder. The mockup looks for these names and will play them automatically once they are here. Do not add stock footage.

## Hero backdrop (first screen)

- `hero.mp4` — full-viewport background on the hero
- `hero.jpg` or `hero.webp` — poster / fallback still (used before the video loads, and if the visitor prefers reduced motion)
- `hero-mobile.mp4` — optional smaller file for mobile. If it is missing, the site uses `hero.mp4`.

Recommended for the hero clip:

- 10–20 seconds, looping cleanly
- About 1080p, H.264 MP4
- Under ~6MB
- No audio (the site plays it muted anyway)

If these files are not present, the hero keeps the red light wash and shows a placeholder: `[Add: hero.mp4 backdrop]`.

## Event clips

- `vid-1.mp4` through `vid-6.mp4`
- Optional posters: `vid-1.jpg` or `vid-1.webp` through `vid-6.jpg` / `vid-6.webp`

### Where they appear

- **vid-1, vid-2, vid-3** — the “See the vibe” row right after the intro, and again in the video wall
- **vid-4, vid-5, vid-6** — the video wall only

Recommended for event clips:

- MP4, H.264
- About 720p
- Under ~8MB each, so the page stays fast
- Audio is muted on the site
